# Dock edge placement (D-11)

## Purpose
Check bottom, top, left, and right placement and dependent popup/minimize anchors.

## Prerequisites
- Windows 11; Dock enabled; at least one pinned and one running app.

## Test Steps
1. Select each edge and inspect icon order, spacing, indicators, and Trash.
2. Open a tooltip, preview, and folder popup near each edge.
3. Minimize and restore a window from each position.

## Expected Behavior
The Dock renders along the selected edge; popups open toward available space and minimize targets match the Dock position.

## Actual Behavior
Not run on Windows 11.

## Recovery
Return to the preferred edge and confirm work-area reservation is cleared after exit.
