# Dock previews (D-6)

## Purpose
Check preview delay, size, window title, buttons, and DWM thumbnail updates.

## Prerequisites
- Windows 11; Dock enabled; an app with two visible windows.

## Test Steps
1. Change preview delay and size in Settings.
2. Hover the app icon and check when the popup appears and its dimensions.
3. Move content in the source window and inspect the preview; use each enabled window button.

## Expected Behavior
Changes apply without restart; live content follows the source window; buttons act on the matching window.

## Actual Behavior
Not run on Windows 11. Verify which options are wired before recording results.

## Recovery
Exit Nexora and confirm no preview popup or taskbar/work-area change remains.
