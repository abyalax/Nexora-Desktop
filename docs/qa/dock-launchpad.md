# Dock and Launchpad sources (D-8)

## Purpose
Check Start Menu/Desktop sources, monitor placement, z-order, and background treatment.

## Prerequisites
- Windows 11; shortcuts in Start Menu and Desktop; two displays if available.

## Test Steps
1. Refresh the app list and confirm shortcuts from each enabled source appear once.
2. Open Launchpad with each display/follow-Dock setting.
3. Open it over a window and compare the configured z-order and blur behavior.

## Expected Behavior
Source filters and display choice match Settings; app entries launch their targets; dismissal restores prior focus.

## Actual Behavior
Not run on Windows 11. Monitor selection and visual options may not yet be wired.

## Recovery
Close Launchpad and confirm taskbar/work area are unchanged.
